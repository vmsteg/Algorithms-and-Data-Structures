## Теоретическая часть
**Динамический массив** — это структура данных, хранящая элементы в непрерывной области памяти (в куче), размер которой может изменяться во время выполнения программы. В отличие от статического массива, он позволяет автоматически расширяться при добавлении новых элементов.

**Правило трёх и пяти:** Если класс управляет ресурсами (например, динамической памятью), необходимо определить деструктор, конструктор копирования и оператор присваивания (правило трёх). С появлением C++11 к ним добавились конструктор перемещения и оператор присваивания перемещением (правило пяти), что позволяет избегать дорогостоящего копирования за счет «передачи» владения ресурсами.

**Итераторы** — объекты, позволяющие последовательно перебирать элементы контейнера. В случае динамического массива итераторами могут выступать обычные указатели (`T*`).

**Амортизированная сложность `push_back`:** Благодаря стратегии удвоения ёмкости (capacity) при переполнении, средняя сложность добавления элемента в конец составляет O(1), так как дорогостоящие операции перевыделения памяти происходят всё реже.

## Листинг программы

```cpp
#include <iostream>
#include <stdexcept>
#include <utility>

// Шаблонный класс динамического массива (аналог std::vector)
template <typename T>
class Vector {
private:
    T*  data;   // указатель на массив в куче
    int sz;     // количество реально хранимых элементов
    int cap;    // количество элементов, помещающихся без перевыделения (cap >= sz)

public:
    // Конструктор по умолчанию: пустой вектор, память не выделяется
    Vector() : data(nullptr), sz(0), cap(0) {}

    // Конструктор размера: n элементов, инициализируются T()
    explicit Vector(int n) : data(nullptr), sz(n), cap(n) {
        if (n > 0) data = new T[n]();
    }

    // Конструктор копирования: выполняется глубокое копирование (создаётся новый массив)
    Vector(const Vector& other) : data(nullptr), sz(other.sz), cap(other.cap) {
        if (cap > 0) {
            data = new T[cap];
            for (int i = 0; i < sz; ++i) data[i] = other.data[i];
        }
    }

    // Конструктор перемещения: указатель забирается у источника, сложность O(1)
    Vector(Vector&& other) noexcept
        : data(other.data), sz(other.sz), cap(other.cap) {
        other.data = nullptr;
        other.sz = 0;
        other.cap = 0;
    }

    // Деструктор: массив, выделенный через new[], освобождается
    ~Vector() { delete[] data; }

    // Присваивание копированием по идиоме copy-and-swap
    Vector& operator=(const Vector& other) {
        if (this != &other) {          // выполняется защита от самоприсваивания
            Vector temp(other);        // данные копируются во временный объект
            swap(temp);                // затем содержимое обменивается
        }
        return *this;
    }

    // Присваивание перемещением: своя память освобождается, чужая забирается
    Vector& operator=(Vector&& other) noexcept {
        if (this != &other) {
            delete[] data;
            data = other.data;
            sz   = other.sz;
            cap  = other.cap;
            other.data = nullptr;
            other.sz = 0;
            other.cap = 0;
        }
        return *this;
    }

    // Доступ по индексу: границы проверяются
    T& operator[](int i) {
        if (i < 0 || i >= sz) throw std::out_of_range("Index out of range");
        return data[i];
    }
    const T& operator[](int i) const {
        if (i < 0 || i >= sz) throw std::out_of_range("Index out of range");
        return data[i];
    }

    // Геттеры (поля приватные)
    int size()     const { return sz;  }
    int capacity() const { return cap; }
    bool empty()   const { return sz == 0; }

    // Выделяется новая память большего размера, элементы переносятся
    void reserve(int newCap) {
        if (newCap <= cap) return;      // памяти уже хватает
        T* newData = new T[newCap];
        for (int i = 0; i < sz; ++i) newData[i] = data[i];
        delete[] data;
        data = newData;
        cap  = newCap;
    }

    // Добавление в конец: при переполнении ёмкость удваивается
    void push_back(const T& value) {
        if (sz >= cap) reserve(cap == 0 ? 1 : cap * 2);
        data[sz++] = value;
    }

    // Удаление последнего элемента
    void pop_back() {
        if (empty()) throw std::underflow_error("Vector is empty");
        --sz;
    }

    // Обмен содержимым (используется в copy-and-swap)
    void swap(Vector& other) noexcept {
        std::swap(data, other.data);
        std::swap(sz,   other.sz);
        std::swap(cap,  other.cap);
    }

    // Итераторы: в данном случае это просто указатели
    T*       begin()       { return data;      }
    T*       end()         { return data + sz; }
    const T* begin() const { return data;      }
    const T* end()   const { return data + sz; }

    // ============================================================
    //                Вариант 5: операторы + и *
    // ============================================================

    // Конкатенация: создаётся новый вектор, элементы копируются
    // Сложность O(n + m), где n = this->sz, m = other.sz.
    Vector operator+(const Vector& other) const {
        Vector result;
        result.reserve(sz + other.sz);          // память выделяется заранее
        for (int i = 0; i < sz; ++i)       result.push_back(data[i]);
        for (int i = 0; i < other.sz; ++i) result.push_back(other.data[i]);
        return result;
    }

    // Умножение на число: Vector * scalar
    // Текущий вектор копируется, каждый элемент умножается. O(n).
    Vector operator*(const T& k) const {
        Vector result(*this);
        for (int i = 0; i < result.sz; ++i)
            result.data[i] = result.data[i] * k;
        return result;
    }

    // Умножение на число: scalar * Vector (дружественная перегрузка)
    friend Vector operator*(const T& k, const Vector& v) {
        return v * k;                           // переиспользуется уже написанный оператор
    }
};

int main() {
    setlocale(LC_ALL, "ru");

    Vector<int> a, b;
    for (int i = 1; i <= 5; ++i) a.push_back(i);        // a = [1,2,3,4,5]
    for (int i = 1; i <= 3; ++i) b.push_back(i * 10);   // b = [10,20,30]

    // Утилита вывода: вектор перебирается через range-based for
    auto print = [](const char* name, const Vector<int>& v) {
        std::cout << name << " = ";
        for (int x : v) std::cout << x << " ";
        std::cout << "\n";
    };

    print("a", a);
    print("b", b);
    print("a + b", a + b);             // конкатенация
    print("a * 3", a * 3);             // Vector * scalar
    print("3 * a", 3 * a);             // scalar * Vector
    print("(a + b) * 2", (a + b) * 2); // композиция операторов

    return 0;
}
```

## Анализ сложности

| Операция | Сложность | Комментарий |
| :--- | :--- | :--- |
| Конструктор по умолчанию | O(1) | Только инициализация полей |
| Конструктор копирования | O(n) | Глубокое копирование `sz` элементов |
| Конструктор перемещения | O(1) | Только передача указателя, без копирования данных |
| Оператор присваивания копированием | O(n) | Копирование элементов через copy-and-swap |
| `operator[]` | O(1) | Прямой доступ по индексу |
| `push_back` | амортизированно O(1) | За счет удвоения ёмкости (стратегия расширения) |
| `pop_back` | O(1) | Только уменьшение `sz` |
| `reserve` | O(n) | Копирование/перемещение всех элементов в новую память |
| `operator+` (конкатенация) | O(n + m) | Копирование элементов двух векторов в новый |
| `operator*` (умножение на число)| O(n) | Копирование вектора и умножение каждого элемента |

## Ответы на контрольные вопросы

1. **Почему динамический массив называется «динамическим»?**
   Потому что его размер определяется во время выполнения программы (а не на этапе компиляции) и может изменяться. Память для него выделяется в куче (heap), а не на стеке.

2. **Что такое ёмкость (capacity) и чем она отличается от размера (size)?**
   `size` — количество элементов, которые реально хранятся в векторе в данный момент. `capacity` — количество элементов, под которые уже выделена память. `capacity` всегда больше или равно `size`. Если `size` превышает `capacity`, происходит перевыделение памяти.

3. **Почему при расширении массива ёмкость удваивается, а не увеличивается на фиксированное число?**
   Удвоение обеспечивает амортизированную сложность вставки O(1). Если бы ёмкость увеличивалась на 1, то при каждой вставке приходилось бы копировать весь массив, что привело бы к квадратичной сложности O(N²) на N вставок.

4. **Какова амортизированная сложность операции push_back? Почему?**
   O(1). Большинство вставок происходят за O(1) (просто запись в конец). Дорогостоящие операции перевыделения с копированием происходят редко (при удвоении ёмкости), и их суммарный вклад, распределенный на все операции добавления, стремится к константе.

5. **Что такое «правило трёх»? Когда оно применяется?**
   Это правило гласит: если классу требуется пользовательский деструктор, конструктор копирования или оператор присваивания копированием, то ему, скорее всего, нужны все три. Применяется к классам, управляющим ресурсами (например, динамической памятью).

6. **Что такое «правило пяти»? Чем оно отличается от «правила трёх»?**
   Это расширение правила трёх, включающее также конструктор перемещения и оператор присваивания перемещением. Отличие в том, что оно оптимизирует работу с временными объектами (rvalue), позволяя «забирать» ресурсы, а не копировать их.

7. **В чём разница между конструктором копирования и оператором присваивания?**
   Конструктор копирования создаёт *новый* объект на основе существующего. Оператор присваивания заменяет состояние *уже существующего* объекта, поэтому перед копированием он должен освободить старые ресурсы.

8. **Зачем нужна проверка `if (this != &other)` в операторе присваивания?**
   Это защита от самоприсваивания (когда объект присваивается сам себе). Без этой проверки при освобождении старых ресурсов мы бы уничтожили данные, которые затем пытались бы скопировать.

9. **Что такое итератор? Как он связан с указателем?**
   Итератор — это объект, предоставляющиый доступ к элементам контейнера и позволяющий перемещаться между ними. В `std::vector` и нашей реализации итератор реализован как обычный указатель (`T*`), так как данные хранятся непрерывно.

10. **Зачем нужны методы `begin()` и `end()`?**
    Они возвращают итераторы на первый элемент и на элемент, следующий за последним. Эта пара итераторов `[begin, end)` задаёт диапазон для перебора элементов, что используется в циклах `range-based for` и алгоритмах STL.

11. **Как реализовать `range-based for` для своего контейнера?**
    Достаточно реализовать методы `begin()` и `end()` (возвращающие указатели или объекты-итераторы), и компилятор автоматически сможет перебирать ваш контейнер в цикле `for (auto x : container)`.

12. **Что такое «глубокое копирование»? Чем оно отличается от «поверхностного»?**
    Глубокое копирование создаёт полностью независимую копию объекта, включая копирование всех данных в динамической памяти. Поверхностное копирование копирует только значения полей (указатели), из-за чего два объекта начинают указывать на одну и ту же память, что приводит к ошибкам при удалении.

13. **Что такое семантика перемещения и зачем она нужна?**
    Это возможность «перемещать» ресурсы из одного объекта в другой без их копирования. Нужна для повышения производительности, особенно при возврате объектов из функций и перевыделении памяти в контейнерах.

14. **Почему конструктор перемещения помечается `noexcept`?**
    Контейнеры STL (например, `std::vector`) при перевыделении памяти используют перемещение вместо копирования, только если конструктор перемещения гарантирует отсутствие исключений. Это необходимо для сохранения строгих гарантий безопасности исключений.

15. **Как правильно освобождать память в деструкторе?**
    Использовать `delete[] data;` для массивов, так как память выделялась через `new T[n]`. Использование просто `delete` привело бы к неопределённому поведению.
