## Теоретическая часть

**Анализ сложности алгоритмов.** Это математический способ оценки эффективности алгоритма в зависимости от размера входных данных. Выделяют временную сложность (сколько времени выполняется алгоритм) и пространственную (сколько памяти он использует).

**О-нотация (Big O).** Это математическая запись, описывающая асимптотическое поведение функции при стремлении аргумента к бесконечности. О-нотация показывает, как быстро растёт время работы алгоритма при увеличении входных данных, отбрасывая константы и младшие члены.
Основные классы сложности:
*   **O(1)** — константная (доступ по индексу в массиве).
*   **O(log n)** — логарифмическая (бинарный поиск).
*   **O(n)** — линейная (линейный поиск, сумма элементов).
*   **O(n log n)** — линейно-логарифмическая (быстрая сортировка).
*   **O(n²)** — квадратичная (пузырьковая сортировка).

**Шаблоны функций и классов.** Шаблоны в C++ позволяют писать обобщённый код, который работает с разными типами данных. Шаблон функции объявляется с помощью `template <typename T>`, где `T` — параметризованный тип. Шаблонный класс позволяет создавать универсальные структуры данных (например, контейнеры), которые могут хранить элементы любого типа.

**Экспериментальный анализ.** Для замера времени выполнения используется библиотека `<chrono>`, позволяющая замерять время в микросекундах. Чтобы получить точные данные, операции выполняются многократно в цикле.

## Листинг программы
```cpp
#include <iostream>
#include <stdexcept>
#include <chrono>
#include <deque>
#include <vector>
using namespace std;
using namespace chrono;

template <typename T>
class Deque {
private:
    T* data;          // массив для элементов
    int capacity;     // текущая ёмкость
    int frontIndex;   
    int backIndex;    
    int count;        

    // O(n) — расширение массива в 2 раза
    void resize() {
        int newCapacity = capacity * 2;
        T* newData = new T[newCapacity];
        for (int i = 0; i < count; i++)
            newData[i] = data[(frontIndex + i) % capacity];   // копирование по порядку
        delete[] data;
        data = newData;
        capacity = newCapacity;
        frontIndex = 0;
        backIndex = count - 1;
    }

public:
    // O(1) — конструктор
    Deque(int initialCapacity = 8)
        : capacity(initialCapacity), frontIndex(0), backIndex(-1), count(0)
    {
        if (initialCapacity <= 0) throw invalid_argument("capacity > 0");
        data = new T[capacity];
    }

    ~Deque() { delete[] data; }

    // запрет копирования во избежание двойного delete
    Deque(const Deque&) = delete;
    Deque& operator=(const Deque&) = delete;

    // O(1) амортизированно
    void push_front(const T& value) {
        if (count == capacity) resize();
        frontIndex = (frontIndex - 1 + capacity) % capacity;   // сдвиг влево по кругу
        data[frontIndex] = value;
        count++;
    }

    // O(1) амортизированно
    void push_back(const T& value) {
        if (count == capacity) resize();
        backIndex = (backIndex + 1) % capacity;                // сдвиг вправо по кругу
        data[backIndex] = value;
        count++;
    }

    // O(1)
    T pop_front() {
        if (count == 0) throw out_of_range("Deque пуст");
        T value = data[frontIndex];                            // сохранение значения
        frontIndex = (frontIndex + 1) % capacity;              // сдвиг вправо
        count--;
        return value;
    }

    // O(1)
    T pop_back() {
        if (count == 0) throw out_of_range("Deque пуст");
        T value = data[backIndex];                             // сохранение значения
        backIndex = (backIndex - 1 + capacity) % capacity;     // сдвиг влево
        count--;
        return value;
    }

    // O(1) — вычисление позиции по формуле
    T& operator[](int index) {
        if (index < 0 || index >= count) throw out_of_range("Индекс вне диапазона");
        return data[(frontIndex + index) % capacity];
    }

    // O(1) — для константного объекта
    const T& operator[](int index) const {
        if (index < 0 || index >= count) throw out_of_range("Индекс вне диапазона");
        return data[(frontIndex + index) % capacity];
    }

    int size()  const { return count; }         // O(1)
    bool empty() const { return count == 0; }   // O(1)

    // O(n) — вывод всех элементов по очереди
    void print() const {
        cout << "[";
        for (int i = 0; i < count; i++) {
            cout << data[(frontIndex + i) % capacity];
            if (i < count - 1) cout << ", ";
        }
        cout << "]" << endl;
    }
};

// Замер времени выполнения лямбды в микросекундах
template <typename Func>
long long measureTime(Func func) {
    auto start = high_resolution_clock::now();
    func();
    auto end = high_resolution_clock::now();
    return duration_cast<microseconds>(end - start).count();
}

int main() {
    setlocale(LC_ALL, "ru");
    cout << "1. демонстрация Deque:" << endl;
    Deque<int> dq(4);
    dq.push_back(10);    // [10]
    dq.push_back(20);    // [10, 20]
    dq.push_front(5);    // [5, 10, 20]
    dq.push_front(1);    // [1, 5, 10, 20]
    dq.print();

    dq.push_back(30);    // вызов resize: [1, 5, 10, 20, 30]
    dq.print();

    cout << "pop_front: " << dq.pop_front() << endl;   // удаление 1
    cout << "pop_back:  " << dq.pop_back() << endl;   // удаление 30
    dq.print();                                        // [5, 10, 20]

    cout << "dq[1] = " << dq[1] << ", size = " << dq.size() << endl;

    // 2. Сравнение с std::deque
    cout << "\n2. сравнение с std::deque:" << endl;
    cout << "N\t\tcustom\t\tSTL" << endl;

    vector<int> sizes = { 10000, 50000, 100000 };
    for (int n : sizes) {
        Deque<int> custom;
        std::deque<int> stl;

        // тест Deque: push/pop с обоих концов
        long long tCustom = measureTime([&]() {
            for (int i = 0; i < n; i++) { custom.push_back(i); custom.push_front(i); }
            for (int i = 0; i < n; i++) { custom.pop_back();   custom.pop_front(); }
            });

        // тест для STL
        long long tSTL = measureTime([&]() {
            for (int i = 0; i < n; i++) { stl.push_back(i); stl.push_front(i); }
            for (int i = 0; i < n; i++) { stl.pop_back();   stl.pop_front(); }
            });

        cout << n << "\t\t" << tCustom << "\t\t" << tSTL << endl;
    }

    return 0;
}
```

## Анализ сложности реализованных операций

Контейнер `Deque` реализован на основе **кольцевого буфера** (циклического массива). Это позволяет эффективно добавлять и удалять элементы с обоих концов.

| Операция | Сложность | Обоснование |
| :--- | :--- | :--- |
| `push_front` | **O(1)** амортизированно | Индекс `frontIndex` циклически сдвигается влево. Элементы не сдвигаются физически в памяти. Раз в N шагов происходит `resize` (O(n)), но в пересчёте на одну операцию это дает O(1). |
| `push_back` | **O(1)** амортизированно | Индекс `backIndex` циклически сдвигается вправо. Аналогично `push_front`. |
| `pop_front` | **O(1)** | `frontIndex` сдвигается вправо, значение возвращается. |
| `pop_back` | **O(1)** | `backIndex` сдвигается влево, значение возвращается. |
| `operator[]` | **O(1)** | Позиция элемента вычисляется математически по формуле `(frontIndex + index) % capacity`. Нет циклов. |
| `size`, `empty` | **O(1)** | Возвращают значение переменной `count`. |

## Ответы на контрольные вопросы

1. **Что такое О-нотация и зачем она нужна?**
   О-нотация — это математическая запись для описания асимптотической сложности алгоритма. Она нужна для оценки того, как быстро будет расти время выполнения или объём потребляемой памяти при увеличении размера входных данных (n), без привязки к конкретному железу.

2. **Какая сложность у доступа к элементу массива по индексу? Почему?**
   O(1) — константная. Потому что в памяти элементы массива лежат непрерывно, и адрес нужного элемента вычисляется по формуле: `адрес_начала + индекс * размер_элемента`. Это занимает одинаковое время при любом размере массива.

3. **Какая сложность у бинарного поиска? Почему?**
   O(log n). На каждом шаге область поиска делится ровно пополам. Чтобы найти элемент в массиве из n элементов, нужно сделать около log₂(n) шагов (например, для 1024 элементов — 10 шагов).

4. **Что означает сложность O(n log n)? Приведите пример алгоритма.**
   Это линейно-логарифмическая сложность. Означает, что алгоритм выполняет n операций, каждая из которых требует log n времени. Пример: эффективные алгоритмы сортировки — быстрая сортировка (QuickSort) и сортировка слиянием (MergeSort).

5. **Что такое амортизированный анализ? Приведите пример.**
   Это метод анализа, который усредняет стоимость операции за длительное время. Пример: в `std::vector` (и в нашем `Deque`) операция `push_back` обычно занимает O(1). Но когда массив заполнен, происходит перевыделение памяти и копирование всех элементов — O(n). Однако это происходит редко (каждый раз ёмкость удваивается), поэтому в среднем (амортизированно) одна операция `push_back` всё равно занимает O(1).

6. **Какая сложность у двух вложенных циклов по n итераций каждый?**
   O(n²). Внешний цикл делает n итераций, и для каждой из них внутренний цикл делает ещё n итераций. Итого n * n = n² операций.

7. **Какая сложность у рекурсивного вычисления чисел Фибоначчи?**
   O(2ⁿ) — экспоненциальная. Каждый вызов функции порождает два новых вызова, что приводит к сильному ветвлению. Количество вызовов растёт экспоненциально.

8. **Что такое шаблоны функций? Как их объявить и использовать?**
   Это обобщённые функции, которые могут работать с разными типами данных. Объявление: `template <typename T> T max(T a, T b)`. Использование: `max(5, 10)` или явно `max<int>(5, 10)`. Компилятор сам подставит нужный тип.

9. **Что такое шаблоны классов? Как их объявить и использовать?**
   Это классы, параметризованные типами. Объявление: `template <typename T> class Deque { ... };`. Использование: `Deque<int> dq;`, `Deque<string> strDq;`.

10. **В чём преимущество шаблонов перед перегрузкой функций?**
    Шаблоны позволяют написать логику один раз и использовать её для любого типа (включая пользовательские), а не дублировать код для каждого типа (int, double, string) вручную. Это уменьшает дублирование и облегчает поддержку.

11. **Как указать, что шаблонный параметр - тип?**
    С помощью ключевого слова `typename` (или `class`): `template <typename T>`.

12. **Можно ли создать шаблон с несколькими параметрами типов?**
    Да. Например: `template <typename T1, typename T2> class Pair { ... };`.

13. **Как провести экспериментальное измерение времени выполнения?**
    Использовать библиотеку `<chrono>`. Зафиксировать время до (`high_resolution_clock::now()`), выполнить операцию, зафиксировать время после, найти разницу и перевести в нужные единицы (`duration_cast<microseconds>`).

14. **Почему при измерении времени нужно выполнять операцию многократно?**
    Потому что современные процессоры работают очень быстро, и одна операция может занять наносекунды. Погрешность системных часов слишком велика для замера одного действия. Выполняя операцию в цикле (например, 1000 или 100 000 раз), мы получаем измеримое время, которое можно корректно усреднить.

15. **Что важнее: сложность алгоритма или константа?**
    Зависит от размера данных (n). При малых n решающую роль играет константа (например, сложный алгоритм с O(1) может быть медленнее простого O(n) из-за накладных расходов). Но при больших n (асимптотика) более важна сложность: алгоритм с O(n log n) всегда обгонит алгоритм с O(n²).
